# История изменений

## 1.0.2.6 — исправление перезапуска
- Убран ранний выход «уже работает» в start(): мешал смене стратегии и профилей.
- start() всегда останавливает старый winws и запускает заново.

## 1.0.2.5 — индикатор статуса в трее
- В меню трея сверху: ● Включено · стратегия / ● Выключено / ● Нет zapret.
- Tooltip иконки трея тоже показывает стратегию.

## 1.0.2.4 — трей и уведомления
- В меню трея: Перезапустить, Подобрать стратегию, Проверить систему.
- Уведомления показывают иконку Zapret вместо пустой системной.

## 1.0.2.3 — профили Xbox / Minecraft / X / Roblox
- Добавлены готовые профили: «Xbox Microsoft Minecraft», «X Twitter», «Roblox».
- Списки доменов без широких CDN (amazonaws, cloudfront и т.п.), чтобы обход не тормозил весь интернет.
- Новые пресеты появляются у уже установленных пользователей (если файла профиля ещё нет).

## 1.0.2.2 — надёжный запуск и диагностика WinDivert
- Проверка процесса winws.exe теперь использует и дескриптор LAST_PROC, и tasklist (меньше ложных «не появился»).
- Ожидание старта увеличено до 5 секунд (раньше 1.5–2.5 с — winws часто не успевал).
- Запрет повторного запуска, если winws.exe уже работает.
- Отдельная диагностика драйверов WinDivert / WinDivert14 и проверка файлов на блокировку антивирусом (PermissionError).
- Более подробные сообщения при отсутствии WinDivert.dll / WinDivert64.sys.

## 1.0.2.1 — исправление запуска и обновление интерфейса
- Исправлена обработка BAT-экранирования `^!`, чтобы прямой запуск winws не передавал буквальный `^!` в аргументах.
- Диагностика читает отдельный журнал BAT-запуска и показывает вывод неудачного запуска.
- Разделы «Приложение», «Папки и версии», «Управление версиями и бэкапы» и «Журнал» объединены в одну сворачиваемую карточку.
- Раздел «Оформление» перемещён сразу после «О приложении».
- Настройки сворачивания приведены в соответствие с новой структурой разделов.
- Сохранены темы, профили, анимации и остальные настройки предыдущего обновления.

# Журнал изменений

Формат версий: `MAJOR.MINOR.PATCH`. Пререлизы помечаются суффиксом, например `1.0.3-beta.1`.

## [1.0.4]
- Если обход не запустился, программа показывает причину в журнале и объясняет типичные случаи: WinDivert64.sys удалил антивирус, нет прав, драйвер заблокирован Windows, неподходящая стратегия, не хватает библиотеки.
- «Проверить систему» делает пробный запуск выбранной стратегии на несколько секунд и показывает, что напечатал winws.
- Прямой запуск и запуск через .bat пишут в разные журналы (`winws.log` и `winws-bat.log`), чтобы ошибка не затиралась.

## [1.0.3]
- Вкладки: парящая панель с плавной подсветкой выбранной вкладки и индикатором, заголовки страниц.
- Страница «Сайты» переработана: карточки сайтов со статусом и временем ответа, сводка «доступно N из M», быстрое добавление популярных сайтов, проверка каждого сайта отдельно, автопроверка после включения обхода.
- Оформление: мини-окно предпросмотра (показывает тему, акцент, шрифт, углы и плотность сразу, а при наведении на образец темы или цвета показывает вариант до применения), 14 цветов акцента с гарантией читаемой подписи, три режима плотности (компактная, обычная, просторная), отключение анимаций (переходы становятся мгновенными), сброс к умолчанию.
- Настройки: старые файлы `config.json` читаются без потери значений, повреждённый файл не роняет программу (его копия сохраняется как `config.json.bad`), запись идёт через временный файл.
- Автотесты оформления и настроек (`python -m unittest discover -s tests`) и проверка на GitHub при каждом пуше.
- Списки (`list-general.txt`, `ipset-all.txt` и другие) подгружаются из официального репозитория zapret; автообновление раз в 12 часов и кнопка «Обновить списки с GitHub».
- Диагностика системы (права, файлы zapret, WinDivert, списки, доступ к GitHub).
- Сборка для Windows 7 (`ZapretGUI-Win7.exe`, Python 3.8 + Qt 5.15). Приложение само выбирает нужный файл при обновлении.
- Скрипт `publish.bat` для публикации на GitHub и выпуска релиза.

## [1.0.2]
- Скрытый запуск обхода: без окна `winws` и без значка на панели задач.
- Полное выключение: останавливаются `winws`, служба `zapret` и драйвер WinDivert.
- Автоматическая загрузка и обновление zapret с GitHub (Flowseal/zapret-discord-youtube), бэкапы старых версий.
- Профили доменов (Telegram, Discord, свои), редактор списков, проверка сайтов, подбор стратегии.
- Темы, значок в трее (зелёный/красный), адаптивный интерфейс, анимации.
- Обновление самого приложения с GitHub: релизы и пререлизы, бэкапы версий и откат.
