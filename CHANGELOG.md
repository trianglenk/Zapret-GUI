# Журнал изменений

Формат версий: `MAJOR.MINOR.PATCH`. Пререлизы помечаются суффиксом, например `1.0.3-beta.1`.

## [1.0.2]
- Скрытый запуск обхода: без окна `winws` и без значка на панели задач.
- Полное выключение: останавливаются `winws`, служба `zapret` и драйвер WinDivert.
- Автоматическая загрузка и обновление zapret с GitHub (Flowseal/zapret-discord-youtube), бэкапы старых версий.
- Профили доменов (Telegram, Discord, свои), редактор списков, проверка сайтов, подбор стратегии.
- Темы, значок в трее (зелёный/красный), адаптивный интерфейс, анимации.
- Обновление самого приложения с GitHub: релизы и пререлизы, бэкапы версий и откат.
