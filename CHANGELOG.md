## 1.0.3 — анимации, шрифт, версии zapret, профили
- Анимации: по клику демо-блок едет вправо → влево → вправо (3 хода). Плавная и быстрая — с разной скоростью; «Нет» — мгновенные прыжки.
- Шрифт: только два размера под экран — «Компактный» (9 pt) и «Обычный» (10.5 pt).
- Профили: кнопка «Загрузить профили с GitHub» тянет списки из github.com/trianglenk/zapretgui.list.
- Выпадающие списки стратегий (BAT) и версий zapret в стиле приложения.
- Баннер обновления: «Обновить» / «Закрыть» с описанием новой версии.
- Локальные бэкапы zapret: переключение без повторного скачивания.

## Исправление переключения BAT-стратегий (Firefox / HTTP2 / QUIC)
- При обычном переключении BAT завершается только предыдущий winws.exe; системные службы и драйверы WinDivert не выгружаются каждый раз.
- Добавлено ожидание фактического завершения winws.exe. Если процесс не остановился за 8 секунд, новый BAT не запускается поверх старого, а GUI получает понятную ошибку.
- Полная остановка служб/драйверов оставлена для явного выключения обхода.
- Убрана очистка DNS при каждом переключении: она не сбрасывает уже открытые HTTP/2/QUIC-соединения Firefox и не решает зависание существующих сессий.
- Добавлены тесты того, что переключение не останавливает WinDivert и не запускает новый фильтр при живом старом процессе.

# Журнал изменений

Формат версий: `MAJOR.MINOR.PATCH`. Пререлизы помечаются суффиксом, например `1.0.3-beta.1`.

## [1.0.4]
- Если обход не запустился, программа показывает причину в журнале и объясняет типичные случаи: WinDivert64.sys удалил антивирус, нет прав, драйвер заблокирован Windows, неподходящая стратегия, не хватает библиотеки.
- «Проверить систему» делает пробный запуск выбранной стратегии на несколько секунд и показывает, что напечатал winws.
- Прямой запуск и запуск через .bat пишут в разные журналы (`winws.log` и `winws-bat.log`), чтобы ошибка не затиралась.

## [1.0.3]
- Вкладки: парящая панель с плавной подсветкой выбранной вкладки и индикатором, заголовки страниц.
- Страница «Сайты» переработана: карточки сайтов со статусом и временем ответа, сводка «доступно N из M», быстрое добавление популярных сайтов, проверка каждого сайта отдельно, автопроверка после включения обхода.

- Диагностика системы (права, файлы zapret, WinDivert, списки, доступ к GitHub).
- Сборка для Windows 7 (`ZapretGUI-Win7.exe`, Python 3.8 + Qt 5.15). Приложение само выбирает нужный файл при обновлении.
- Скрипт `publish.bat` для публикации на GitHub и выпуска релиза.
